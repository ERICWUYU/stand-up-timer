# MVP 验收标准

## 自动化验证

- [x] 运行 `swift test`，56/56 个测试通过。
- [x] `Scripts/build-app.sh` 产出签名 `.app`，语言与通知资源完整。
- [x] 新计时器默认为 25 分钟专注阶段。
- [x] 开始后状态变为运行中。
- [x] 暂停后剩余时间不继续减少。
- [x] 继续后从暂停时的剩余时间开始。
- [x] 专注到期后切换到 5 分钟休息阶段。
- [x] 休息到期后切换回专注阶段。
- [x] 重置恢复当前阶段的完整时长。
- [x] 跳过能立即切换到下一阶段。
- [x] 电脑休眠或界面暂停刷新不会造成累计计时误差。
- [x] 四轮模式按“专注 1 → 短休 → 专注 2 → 短休 → 专注 3 → 短休 → 专注 4 → 15 分钟长休”自动推进。
- [x] 四轮模式长休结束后停止，回到普通空闲专注且轮次归零。
- [x] 四轮模式在暂停、跳过、重置、取消和重启恢复后仍保持正确轮次与截止时间。

## 人工验证

- [x] 应用启动后，菜单栏能看到状态图标，展开面板能看到剩余时间。
- [x] 开始、暂停、继续、重置和跳过均可用。
- [x] 第一次需要通知时，系统正确显示权限请求。
- [x] 将专注和休息临时设为 10 秒后，两次系统通知都实际出现。
- [x] 一键开始四轮模式后，无需再次点击即可完成前三次短休后的下一轮启动。
- [x] 短休结束自动开始下一轮专注；第 4 次专注结束后进入长休，长休结束回到普通空闲专注。
- [x] 退出并重新打开应用后，运行中与暂停中的计时按真实截止时间或冻结剩余时间恢复。
- [x] 专注结束和休息结束通知正常送达，所选系统提示音正常播放。
- [x] 中文与英文界面切换正常，关键文案完整显示。
- [x] 四轮、设置和退出等底部控件保持单行，无换行或截断。
- [ ] 通知被拒绝时，应用给出可理解的说明。
- [ ] 切换到其他应用后，提醒仍然正常。
- [ ] Mac 睡眠后唤醒，剩余时间根据真实时间正确更新。
- [ ] 修改时间和声音设置，重启应用后设置仍保留。
- [ ] 四轮模式清楚显示当前轮次，并能随时取消回到普通空闲专注。
- [ ] 使用短测试时长时，四次专注、三次短休和一次长休的通知顺序正确。
- [ ] 应用不要求联网，也不创建账号。

## 完成定义

只有自动化验证通过，并且人工通知测试实际观察成功，才可以称为 MVP 完成。
