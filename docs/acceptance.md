# MVP 验收标准

## 自动化验证

- [x] 运行 `swift test`，78/78 个测试通过。
- [x] `Scripts/build-app.sh` 产出签名 `.app`，语言与通知资源完整。
- [x] 新计时器默认为 25 分钟专注阶段。
- [x] 开始后状态变为运行中。
- [x] 暂停后剩余时间不继续减少。
- [x] 继续后从暂停时的剩余时间开始。
- [x] 专注到期后切换到 5 分钟休息阶段。
- [x] 休息到期后切换回专注阶段。
- [x] 重置恢复当前阶段的完整时长。
- [x] 跳过能立即切换到下一阶段。
- [x] 电脑休眠或界面暂停刷新不会造成累计计时误差。
- [x] 四轮模式按“专注 1 → 短休 → 专注 2 → 短休 → 专注 3 → 短休 → 专注 4 → 长休（默认 15 分钟）”自动推进。
- [x] 四轮模式长休结束后停止，回到普通空闲专注且轮次归零。
- [x] 四轮模式在暂停、跳过、重置、取消和重启恢复后仍保持正确轮次与截止时间。
- [x] 普通计时器与 Focus Cycle 使用相互独立的时长；旧专注/休息设置迁移到两种模式，长休首次迁移为 15 分钟。旧设置迁移使用 `InMemoryTimerStorage` 完成隔离自动化验证，没有读取或写入真实 `UserDefaults`。
- [x] 缺失、损坏、NaN、负数和越界时长安全回退默认值。
- [x] 运行或暂停时修改时长不改变当前阶段剩余时间，从下一阶段起生效；空闲时立即更新当前阶段完整时长。
- [x] 快照保存并恢复模式、轮次、当前阶段及当时实际使用的时长。
- [x] 通知时间线使用对应模式的专注、短休与长休时长。

- [x] 第一次需要通知时，系统正确显示权限请求。

- [x] 一键开始四轮模式后，无需再次点击即可完成前三次短休后的下一轮启动。
- [x] 短休结束自动开始下一轮专注；第 4 次专注结束后进入长休，长休结束回到普通空闲专注。

- [x] 专注结束和休息结束通知正常送达，所选系统提示音正常播放。
- [x] 中文与英文界面切换正常，关键文案完整显示。
- [x] 四轮、设置和退出等底部控件保持单行，无换行或截断。

- [ ] Mac 睡眠后唤醒，剩余时间根据真实时间正确更新。
- [ ] 修改时间和声音设置，重启应用后设置仍保留。
- [ ] 四轮模式清楚显示当前轮次，并能随时取消回到普通空闲专注。
- [ ] 使用短测试时长时，四次专注、三次短休和一次长休的通知顺序正确。
- [x] 设置窗口分为“普通计时器”和“Focus Cycle（4 轮）”两区，分别为 2 行和 3 行，窗口紧凑、中英文完整。
- [x] 其他应用在前台时点击设置，设置窗口出现在最前；被遮挡后再次点击可回到最前，重复点击不产生多个窗口。
- [ ] 应用不要求联网，也不创建账号。

## 完成定义

只有自动化验证通过，并且人工通知测试实际观察成功，才可以称为 MVP 完成。
